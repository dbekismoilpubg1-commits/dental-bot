# 🦷 Стоматологический Telegram Бот

Telegram бот с Mini App для стоматологической клиники.

## Деплой на Render (бесплатно, 24/7)

1. Создай аккаунт на [render.com](https://render.com)
2. Нажми **New +** → **Web Service**
3. Подключи GitHub или загрузи папку `bot/`
4. Настройки:
   - **Name:** `dental-bot`
   - **Runtime:** Node
   - **Build Command:** `npm install`
   - **Start Command:** `node bot.js`
5. Добавь переменные окружения:
   - `BOT_TOKEN` = `8635968824:AAFWjCew4QK4cbUjH1-qGHKABp0NrgQFdAg`
   - `MINI_APP_URL` = URL твоего сервиса (например `https://dental-bot.onrender.com`)
6. Нажми **Create Web Service**

Бот будет работать 24/7 без твоего компьютера!

## Локальный запуск

```bash
npm install
npm start
```

## Команды бота

- `/start` — Главное меню
